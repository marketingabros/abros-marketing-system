# Monzù selective context-loading guide

Always load `brand-os/INDEX.yaml`. Then load only the rows needed for the task.

| Task | Required context | Add when relevant | Blocking checks |
|---|---|---|---|
| Social strategy | identity, positioning, audiences, business strategy, current objectives, commercial priorities, management rules, observations | social history, performance sources | Current experience launch status; objective measurement definitions |
| Social content creation | identity, language/tone, relevant experience, management rules, operating status | approved/rejected work, asset manifest, current menu references | Any hours, event, product, price or availability claim; asset rights |
| PPC analysis | current objectives, commercial priorities, advertising history, performance sources | audiences, operating status, website evidence | Google data contamination; currency, attribution and conversion definitions |
| PPC creative | identity, positioning, language/tone, relevant experience, management rules, operating status | audiences, asset manifest, website evidence, approved work | Offer, price, hours, landing-page and asset-rights claims |
| Menu creation | relevant experience, language/tone, management rules, current menu register | visual system, asset manifest | Current products, prices, allergens/dietary facts, final approver |
| Design / mockups | visual system, identity, relevant experience, management rules, asset manifest | approved/rejected work | Canonical colour tokens, fonts/licences, selected asset rights |
| Website work | identity, positioning, language/tone, experiences, management rules, operating status, website register | current menus, objectives, asset manifest | Live operating facts, approved copy, domains/routing and asset rights |
| General brand review | all durable sections and management rules | current context and relevant memory only | Distinguish durable rules from time-sensitive facts and evidence |

## Loading rules

- Load approved examples to judge precedent, never to manufacture a new permanent rule.
- Load rejected examples only when the task needs the specific rejection context.
- Load historical campaigns and menus for comparison, never as current offer information.
- If the requested output would publish an unresolved fact, stop that claim and route the exact question to `HUMAN_REVIEW_REQUIRED.md`.
- Internal reference concepts may guide evaluation but must not appear publicly unless explicitly approved for that use.
